# Commands

20 slash commands organized by project lifecycle stage.

## Initiation

| Command | Description |
|---------|-------------|
| [/project-management:project-charter](./project-charter.md) | Define project scope, objectives, stakeholders, and success criteria |
| [/project-management:stakeholder-map](./stakeholder-map.md) | Map stakeholders by influence and interest with engagement strategies |
| [/project-management:kickoff](./kickoff.md) | Generate a kickoff meeting agenda and preparation checklist |

## Planning

| Command | Description |
|---------|-------------|
| [/project-management:wbs](./wbs.md) | Create a work breakdown structure for a project |
| [/project-management:schedule](./schedule.md) | Build a project schedule with milestones and dependencies |
| [/project-management:resource-plan](./resource-plan.md) | Plan team allocation, roles, and capacity |
| [/project-management:risk-register](./risk-register.md) | Create a risk register with identification, scoring, and mitigation strategies |
| [/project-management:communication-plan](./communication-plan.md) | Define stakeholder communication cadence, channels, and ownership |

| Command | Description |
|---------|-------------|

| [/project-management:decision-log](./decision-log.md) | Record and track project decisions with context and rationale |
| [/project-management:change-request](./change-request.md) | Draft a formal change request with impact analysis |

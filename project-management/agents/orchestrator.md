# Project Management Orchestrator

Select the minimum lifecycle skills needed and preserve one auditable view of scope, decisions, baseline, current state, and ownership.

## Skill registry

| Need | Skill |
|---|---|
| Charter, stakeholders, kickoff | `initiation` |
| WBS, schedule, resources, risks, communications | `planning` |
| Coordination, iteration planning, decisions, changes | `execution` |
| Status, forecasts, health, risks, dependencies | `monitoring` |
| Retrospective, lessons, acceptance, handoff | `closing` |

## Routing

- Use one skill for a clear artifact or ceremony.
- For a health check: monitoring → planning or initiation only where a baseline or authority gap is found → execution for approved recovery actions.
- For a new project: initiation → planning; add execution and monitoring mechanics proportionate to delivery risk.
- For a material change: execution impact analysis → planning baseline revision after approval → monitoring update.
- For closeout: monitoring reconciliation → closing; route open work back to an accountable plan rather than hiding it.

Do not run the whole lifecycle for a small request.

## Shared controls

1. Establish reporting date, project type, approved outcomes, baseline, governance, and source systems.
2. Separate actuals, forecasts, assumptions, commitments, and unapproved requests.
3. Reconcile scope, schedule, cost, quality, resources, risk, dependencies, benefits, and decisions.
4. Show formulas and uncertainty for material forecasts.
5. Preserve privacy and avoid individual surveillance or unsupported performance inference.
6. Surface contradictions with options, impact, and decision owner; do not silently change a baseline.

## Synthesis

Return:

1. current health and evidence cutoff;
2. material variances and causes;
3. risks, dependencies, and decisions;
4. approved recovery or next-phase plan;
5. owners, dates, and escalation paths;
6. assumptions, data gaps, and next review.

Do not create or update tickets, calendars, messages, baselines, budgets, or external systems unless the request authorizes those writes.

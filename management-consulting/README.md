# Management Consulting

End-to-end management consulting workflows — from proposals and SOWs to client deliverables, research, project management, thought leadership, ASE workshops, bench management, contract operations, and structured thinking frameworks.

> **Important**: This plugin assists with consulting workflows but does not provide legal, financial, or professional advice. All outputs should be reviewed by qualified professionals before use with clients.

## Skills

| Skill | Description |
| :--- | :--- |
| [Proposal & SOW](./skills/proposal-sow/SKILL.md) | Proposal and SOW drafting — scoping, pricing models, rate cards, RFP response |
| [Client Deliverables](./skills/client-deliverables/SKILL.md) | Report and deck structures, consulting frameworks, narrative arc, quality standards |
| [Research & Analysis](./skills/research-analysis/SKILL.md) | Market sizing, competitive analysis, benchmarking, industry analysis, trend identification |
| [Project Management](./skills/project-management/SKILL.md) | Workplans, status reporting, RAID logs, risk management, steering committee governance |
| [Point of View](./skills/point-of-view/SKILL.md) | POV and thought leadership — thesis development, writing principles, distribution strategy |
| [Bench Management](./skills/bench-management/SKILL.md) | Bench utilization tracking, activity types, skill matching, staffing optimization, escalation triggers |
| [Contract Management](./skills/contract-management/SKILL.md) | MSAs, SOWs, change orders, billing, renewals, compliance monitoring |
| [Change Management](./skills/change-management/SKILL.md) | ADKAR/Kotter frameworks, stakeholder mapping, communication planning, training design |
| [Workshop Facilitation](./skills/workshop-facilitation/SKILL.md) | Agenda design, ASE methodology, icebreakers, energizers, facilitation techniques |
| [Interview Guides](./skills/interview-guides/SKILL.md) | Question banks by function, interview protocols, cross-interview synthesis |
| [Financial Modeling](./skills/financial-modeling/SKILL.md) | Cost-benefit analysis, NPV/IRR, sensitivity analysis, scenario modeling |

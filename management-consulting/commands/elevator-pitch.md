description: Distill an idea or recommendation into 30-second, 60-second, and 2-minute versions
argument-hint: "[idea, finding, or recommendation to distill]"
---

Use the `structured-thinking` skill's Elevator Pitch framework to create three versions of the specified content: a 30-second version (what + so what), a 60-second version (what + so what + recommendation), and a 2-minute version (context + finding + implication + recommendation + next step). Each version should stand alone and be ready to deliver to a senior executive.

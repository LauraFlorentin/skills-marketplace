# Management Consulting — Commands

Slash commands for Claude Code. Each `.md` file in this directory becomes a `/command-name` you can invoke directly.

## Usage

In Claude Code, type `/` to see available commands from this plugin.

## Planned Commands

Commands will be added as skills are developed:

- `/ai-strategy` — Identify high-impact AI use cases for a client
- `/workflow-analysis` — Map existing business processes to AI opportunities
- `/roi-calculator` — Estimate the business value of AI automation
- `/change-management` — Guide organizations through AI adoption

## Adding a Command

Create a new `.md` file in this directory:

```markdown
---
description: Brief description of what this command does
---

Your command instructions here...
```

The filename becomes the command name (e.g., `ai-strategy.md` → `/ai-strategy`).

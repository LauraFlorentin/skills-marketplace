# Interview Guide

> If you see unfamiliar placeholders or need to check which tools are connected, see [CONNECTORS.md](../CONNECTORS.md).

Create a structured interview guide for stakeholder interviews, including tailored questions, protocol, and synthesis approach.

## Usage

```
/interview-guide <audience> <topic>
```

### Arguments

- `audience` — Who you're interviewing:
  - `executives` — C-suite, SVPs, VPs
  - `operations` — Operational managers and frontline leaders
  - `finance` — CFO, controllers, finance managers
  - `technology` — CTO, IT directors, architects
  - `hr` — CHRO, HR business partners, talent leaders
  - `customers` — External customers or end users
- `topic` — Focus area for the interviews (e.g., current state assessment, pain points, transformation readiness)

## Workflow

### 1. Define Interview Objectives

Clarify what you need to learn: current state understanding, pain point discovery, future state visioning, decision-making dynamics, or hypothesis validation.

### 2. Design Questions

Build a question set using the funnel technique:
- **Opening** (2 min) — Rapport building, role context
- **Broad context** (5 min) — "Tell me about your role and how [topic] works today"
- **Core questions** (25 min) — Targeted questions on key themes
- **Probing** (10 min) — Follow-ups on surprising or important responses
- **Wrap-up** (5 min) — "What haven't I asked that I should have?"

Include 10-15 questions tailored to the audience and function, with probing follow-ups for each.

### 3. Prepare Protocol

- Interview logistics template (scheduling, confirmations, calendar holds)
- Note-taking template with structured fields
- Consent language for recording (if applicable)
- Confidentiality framing for the interviewee

### 4. Plan Synthesis

Define how findings will be aggregated:
- Theme identification through affinity mapping
- Frequency analysis of recurring topics
- Contradiction flagging between stakeholder groups
- Quote capture for anonymized use in deliverables

### 5. Output

Provide:
1. Interview guide with tailored questions and probing follow-ups
2. Interview protocol with timing and logistics
3. Note-taking template
4. Synthesis framework for cross-interview analysis

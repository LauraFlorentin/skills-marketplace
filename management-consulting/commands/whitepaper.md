# Whitepaper / Thought Leadership Drafting

> If you see unfamiliar placeholders or need to check which tools are connected, see [CONNECTORS.md](../CONNECTORS.md).

Draft a publication-ready whitepaper or thought leadership piece using a structured four-stage pipeline.

## Usage

```
/whitepaper <topic or ideas>
```

### Arguments

- `topic` — The subject for the whitepaper:
  - Raw idea dump (observations, notes, client experiences)
  - A specific topic or trend to explore
  - A stage to focus on: `structure`, `draft`, `research`, `format`

## Workflow

### 1. Idea Intake & Structuring

If the user provides raw ideas or observations:
- Identify the core thesis and 2-3 supporting arguments
- Suggest a compelling, differentiated angle
- Propose a whitepaper structure
- Ask clarifying questions: target audience, desired length (short-form 3-5 pages vs. long-form 10-15 pages), tone

### 2. Drafting

Write in a professional but engaging consulting tone:
- Lead with the business problem, not the technology
- Include a strong executive summary that can stand alone
- Use the "So What?" test on every section
- Weave in data points, frameworks, and examples
- End with actionable recommendations

### 3. Research Enhancement

If ~~documents is connected:
- Search for prior firm publications, case studies, and data
- Reference relevant client work (anonymized)

If no data source is connected:
> Use web search to find recent data points, analyst reports, and case studies. Flag claims that need stronger evidence with "[DATA NEEDED]".

### 4. Formatting & Cover Design

Finalize the deliverable:
- Apply consistent heading hierarchy, pull quotes, and callout boxes
- Generate a professional cover page concept
- Suggest 3 alternative titles ranked by impact
- Produce a 2-sentence abstract for distribution

### 5. Output

Provide:
1. Structured whitepaper following the standard template
2. Executive summary (200-300 words, standalone value)
3. 3 title options ranked by impact
4. 2-sentence abstract for distribution
5. Cover page concept description for design team

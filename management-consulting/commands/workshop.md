# Workshop Design

> If you see unfamiliar placeholders or need to check which tools are connected, see [CONNECTORS.md](../CONNECTORS.md).

Design and prepare for a client workshop with a structured agenda, facilitation techniques, and synthesis plan.

## Usage

```
/workshop <type> <topic>
```

### Arguments

- `type` — Workshop format:
  - `discovery` — Explore current state and identify challenges
  - `design` — Co-create solutions, operating models, or processes
  - `alignment` — Build consensus and make decisions among stakeholders
  - `strategy` — Develop strategic direction or priorities
  - `retrospective` — Review project results and capture lessons learned
- `topic` — Subject matter for the workshop

## Workflow

### 1. Define Objectives

Clarify: What decisions need to be made? What output do participants expect? Who has decision authority?

### 2. Design Agenda

Build a time-boxed agenda with energy management:
- **Morning** — High-energy activities: divergent thinking, brainstorming, idea generation
- **After lunch** — Structured activities: analysis, prioritization, evaluation
- **Late afternoon** — Convergent activities: synthesis, decision-making, next steps

### 3. Select Facilitation Techniques

Choose techniques appropriate to the workshop objectives:
- **Idea generation** — Silent brainstorming, round-robin, "How Might We" prompts
- **Prioritization** — Dot voting, impact/effort matrix, criteria-weighted scoring
- **Synthesis** — Affinity mapping, theme clustering, forced ranking
- **Decisions** — Consensus building, informed captain, decision matrix

### 4. Prepare Materials

- Pre-read document for participants (context, objectives, pre-work assignments)
- Facilitation guide with timing, transitions, and contingency plans
- Templates for capturing output (digital or physical)
- Virtual setup if remote (Miro/Mural board, breakout room assignments)

### 5. Output

Provide:
1. Detailed agenda with timing and facilitation notes
2. Pre-read document for participants
3. Facilitation guide with technique instructions
4. Post-workshop synthesis template
5. Follow-up action items and distribution plan

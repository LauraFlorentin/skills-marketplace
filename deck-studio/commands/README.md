# Deck Studio — Commands

Slash commands for Claude Code. Each `.md` file in this directory becomes a `/command-name` you can invoke directly.

## Usage

In Claude Code, type `/` to see available commands from this plugin.

## Available Commands

### Deck Building
| Command | Description |
|---------|-------------|
| `/build-deck` | Full 4-stage pipeline: diagnose → storyboard → content → branded PPTX |
| `/storyboard` | Stages 1–2 only: diagnose context and generate action-title storyboard |
| `/write-slides` | Stage 3 only: write full slide content for an approved storyboard |

### Storytelling
| Command | Description |
|---------|-------------|
| `/story-framework` | Choose the right narrative framework for your presentation |
| `/action-titles` | Rewrite topic titles into action titles (the "so what?" test) |
| `/data-story` | Turn data/analysis into a compelling Data Story Arc narrative |
| `/audience-mode` | Adapt tone and structure for a specific audience type |

### Brand Identity
| Command | Description |
|---------|-------------|
| `/brand-setup` | Configure or update your brand identity |
| `/brand-status` | Show a summary of your current brand config |
| `/brand-ppt` | Brand a PowerPoint or create one from scratch |
| `/brand-doc` | Brand a Word doc or create one from scratch |
| `/brand-logo` | Generate logo SVGs (3 variations) |
| `/brand-social` | Create social media assets (or full kit) |
| `/brand-web` | Create branded HTML artifacts |

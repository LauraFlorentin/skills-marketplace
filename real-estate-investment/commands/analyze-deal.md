Use the **Real Estate Investment Analyzer** skill.

1. Read the orchestrator at `../agents/orchestrator.md`
2. Classify the deal (property type, strategy, geography, stage, complexity)
3. Select and sequence the appropriate agents based on the routing rules
4. Read only the required reference files from `../references/`
5. Execute each agent's analysis and synthesize into an Investment Analysis Memo

Ask the user to describe their deal if they haven't already.

---
description: Run a full investment analysis on a real estate deal using the adaptive multi-agent system
---

Use the **Real Estate Investment Analyzer** skill.

1. Delegate to the `orchestrator` agent provided by this plugin
2. Classify the deal (property type, strategy, geography, stage, complexity)
3. Select and sequence the appropriate agents based on the routing rules
4. Delegate only to the specialist agents required for this deal
5. Execute each agent's analysis and synthesize into an Investment Analysis Memo

Establish an as-of date, verify time-sensitive inputs with authoritative current sources, and ask the user to describe the deal if they have not already.

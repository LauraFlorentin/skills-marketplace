# Real Estate Investment Agents

Claude Code discovers the top-level `.md` files in `agents/` as namespaced plugin agents. This catalog is kept outside that directory so it is not interpreted as an additional agent.

| Agent | Role |
|---|---|
| [orchestrator](../agents/orchestrator.md) | Classify, route, reconcile, and synthesize full analyses |
| [deal-screener](../agents/deal-screener.md) | Preliminary deal triage |
| [property-underwriter](../agents/property-underwriter.md) | Property economics and returns |
| [pro-forma-builder](../agents/pro-forma-builder.md) | Multi-period models |
| [financing-analyzer](../agents/financing-analyzer.md) | Debt and capital comparison |
| [tax-strategist](../agents/tax-strategist.md) | Tax issue spotting and scenarios |
| [stress-tester](../agents/stress-tester.md) | Downside and break-even analysis |
| [syndication-analyzer](../agents/syndication-analyzer.md) | Passive structures, fees, and waterfalls |
| [international-risk-assessor](../agents/international-risk-assessor.md) | Cross-border ownership, currency, and regulatory risk |
| [hospitality-underwriter](../agents/hospitality-underwriter.md) | Hotel, resort, and STR operations |
| [legal-reviewer](../agents/legal-reviewer.md) | Document issue spotting |

Market-data discovery and integration guidance lives in the analyzer skill's [data-sources reference](../skills/real-estate-analyzer/references/data-sources.md).

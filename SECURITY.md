# Security Policy

## Supported versions

Security fixes are applied to the latest version of each plugin on the default
branch. Older plugin versions are not maintained separately.

## Reporting a vulnerability

Do not open a public issue for a vulnerability or include secrets, private data,
or exploit details in a public discussion. Use GitHub's private vulnerability
reporting feature on this repository instead.

Include the affected plugin and version, impact, reproduction steps, and any
suggested mitigation. Reports will be acknowledged as soon as practical and
coordinated disclosure will be preferred.

Plugins and hooks run with the user's permissions. Review a plugin before
installing it, especially when it contains hooks, shell scripts, Python code, or
MCP server configuration.
